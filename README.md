# AFTER HOURS — 친구들과 홀덤

친구들과 함께 하는 **텍사스 홀덤** 웹 게임. 최대 10명, 방 코드/링크로 입장, 가상 칩으로 진행하고 끝나면 정산(누가 누구에게 얼마 송금)까지 계산해 줍니다.
3D 테이블·아바타·카드·칩은 모두 코드로 만들었고(별도 에셋 파일 없음), 서버는 Node.js + WebSocket 입니다.

## 실행

Node.js 24를 설치한 뒤, 압축을 푼 게임 폴더(`package.json`이 있는 폴더)에서 터미널을 열어 입력합니다.

```bash
npm ci
npm start          # http://localhost:3000
```

로컬 실행·외부 서버 배포는 [DEPLOY.md](DEPLOY.md), 디자인 변경은 [DESIGN_NOTES.md](DESIGN_NOTES.md), 검증 범위는 [TEST_REPORT.md](TEST_REPORT.md)를 참고하세요.

같은 와이파이의 친구는 서버를 켤 때 터미널에 나오는 `같은 와이파이 친구:` 주소로 접속합니다.
다른 곳에 있는 친구와 하려면 터널이 필요합니다. 예: `cloudflared tunnel --url http://localhost:3000`

## 주요 기능

- **게임**: 홀덤 규칙 전체(블라인드, 사이드 팟, 올인, 쇼다운 족보 비교와 승패 이유 표시), 폴드한 사람의 카드는 서버가 아예 보내지 않음
- **3D 연출**: 딜러 아바타가 카드를 던지고, 칩 이동·플랍/턴/리버·쇼다운·승리 모션, 효과음과 베팅 음성(콜/레이즈/올인…)
- **모션 그래픽**: 로비 조명과 떠오르는 카드, 테이블의 흐르는 빛, 베팅 파동, 올인·카드 공개 타이틀, 승리 파티클. 상단 효과 버튼과 기기의 움직임 줄이기 설정 지원
- **연습 테이블**: 첫 화면의 '연습 테이블 만들기'로 봇과 혼자 연습 (기본 봇 4명, 대기실에서 총 2~10명으로 추가/삭제). 봇은 무작위가 아니라 카드 강도·포지션·팟 오즈·스택 깊이로 판단하고, 신중형/균형형/공격형 성향이 다릅니다. 화면과 기능은 일반 테이블과 같습니다
- **한마디 말풍선**: 감정표현 4개 아래 입력칸에 최대 10자(이모지도 1자)를 쓰면 내 아바타 위에 약 3.5초 말풍선으로 모두에게 보입니다 (2줄로 접혀 카드·칩을 가리지 않음, 쿨다운은 감정표현과 같음)
- **채팅**: 상단 💬 아이콘(안 읽은 개수 배지)을 누르면 열리는 채팅창 — 폰에서는 아래에서 올라오는 시트, 데스크탑에서는 왼쪽 아래 패널. 한 줄 200자, 1초에 한 번, 최근 100개를 서버가 보관하고 늦게 들어와도 최근 50개를 받습니다. 채팅은 게임 상태와 따로 전달됩니다
- **폰 화면**: 상단 바와 3D 게임 화면은 고정하고 그 아래 'YOUR SEAT' 영역만 스크롤됩니다 (세로 폰 기준)
- **연습 테이블 종료**: 연습에서는 정산이 없습니다. 방장이 '게임 종료'를 누르면 진행 중인 판도 기다리지 않고 바로 메인 화면으로 돌아가고 방은 지워집니다. 사람이 칩과 리바인을 모두 잃거나 1등이 가려져 자동으로 끝날 때도 정산 없이 메인으로 돌아가며 이유를 잠깐 안내합니다
- **대기실 나가기**: 게임 시작 전에는 상단의 '← 메인으로'로 첫 화면에 돌아갈 수 있습니다 (방장이 나가면 다음 사람에게 방장이 넘어가고, 사람이 없으면 방이 지워짐)
- **방 설정**: 바이인 금액(칩 1개 = 1원), 블라인드, N분마다 블라인드 2배, 리바인 최대 횟수
- **종료·정산**: 방장 종료 또는 1등이 가려지면 자동 종료 → 플레이어별 손익과 송금 안내(합계가 정확히 0원이 되도록 정수 연산)
- **방장 권한**: 게임 종료, 일시정지/계속하기, 강제 퇴장
- **그 외**: 감정표현 4종(화남·감사·슬픔·빨리), 내 기기에서만 적용되는 볼륨, 내 차례 알림(문구+알림음), 모바일(세로) 화면 지원

## 때리기 (야구방망이)

상단의 `때리기` 버튼으로 판 도중에도 다른 사람을 때릴 수 있습니다. 규칙은 서버(`engine.js`)가 정하고, 칩이 바뀌면 모두의 화면 숫자가 바로 바뀝니다.

- **비용**: 때린 사람이 1,000칩을 내고 맞은 사람이 받습니다. 앞 스택끼리만 옮기고 팟·베팅은 그대로입니다.
- **쿨다운**: 테이블 전체로 때린 핸드 H, H+1, H+2 는 아무도 못 때리고 H+3 부터 가능합니다.
- **기절**: 맞은 사람은 맞은 뒤 처음 시작하는 핸드를 쉽니다. 자동 폴드가 아니라 패를 아예 받지 않고 블라인드도 안 내며, 그 핸드가 끝나면 깨어납니다.
- **합의금**: 다음 핸드가 시작되기 전에 때린 사람에게 1,500칩을 보내면 기절하지 않습니다 (때린 사람은 +500).
- **방장 스위치**: 방 설정이 아니라 게임 중 방장이 켜고 끄는 스위치입니다 (기본 켜짐). 꺼져도 버튼은 그대로이고 누르면 "방장 권한으로 폭력은 안됩니다." 가 나옵니다.
- **연습 테이블**: 같은 규칙이고, 봇도 합의금을 내고 봇도 때립니다.
- **칩 안전 가드**: 때린 뒤에도 빅블라인드 이상 남아야 하고, 합의금은 1,500칩을 내고도 칩이 남을 때만 낼 수 있습니다. 마지막 핸드·휴식 중, 기절하면 판이 안 돌아가는 경우, 다음 핸드가 4초 안에 시작될 때(맞은 사람이 합의금을 낼 시간)에는 때릴 수 없습니다. 때릴 대상은 번호와 이름을 함께 보내서, 그 사이 자리가 밀려도 엉뚱한 사람이 맞지 않습니다.
- **시험**: `node test-hit.js` (규칙), `node test-hit-server.js` (서버 통합, 포트 3102), `npm test` (규칙 + 서버 통합 + 기존 시험), `npm run test:bots` (봇이 때리고 합의금을 내는 통계 시험, 2분 이상 걸림).

## 카드 자랑하기
- 다른 사람이 모두 폴드해서 이긴 판에서만, 이긴 사람이 핸드가 끝나고 **8초 안에** 한 장(첫째/둘째) 또는 두 장 모두 보여 줄지 정합니다. 안 고른 카드는 서버가 아예 내보내지 않습니다.
- 자랑하면 모두의 화면 가운데에 "과연 카드가 무엇이었을까요?" 연출(두 장 9.5초 · 한 장 6.9초, 소리 포함)이 돌고, 다음 핸드는 연출이 끝날 때까지 늦춰집니다. 한 판에 한 번만 가능합니다.
- 시험: `node test-brag.js` (규칙). 화면 쪽: `public/brag.js`, 소리: `public/sound.js` 의 `brag()`.

## 구조

| 파일 | 역할 |
|---|---|
| `engine.js` | 게임 규칙, 정산 계산 (순수 로직) |
| `server.js` | HTTP + WebSocket 서버 |
| `bot.js` | 연습 테이블의 봇 두뇌 (프리플랍 카드 점수·포지션, 플랍 이후 승률·팟 오즈) |
| `public/index.html` | 로비, 화면 UI, 정산·결과 창 |
| `public/game3d.js` | 3D 테이블/아바타/연출 (three.js) |
| `public/motion.js`, `public/motion.css` | 화면 모션과 효과 설정 |
| `public/table-effects.js` | 3D 테이블 조명·파동 |
| `public/sound.js` | 효과음(Web Audio 합성)·음성·볼륨 |
| `public/vendor/` | three.js |

## 테스트

```bash
node test.js       # 족보, 12,000핸드 시뮬레이션(칩 보존), 정산 2만 건, 리바인/블라인드/종료/강제 퇴장/일시정지/감정표현
```

실제 서버에 가상 플레이어를 접속시켜 N판을 치르며 규칙을 자동 검사하는 시험도 있습니다.

```bash
HOLDEM_FAST=1 PORT=3100 node server.js          # 시험용 서버 (연출 대기 없음)
URL=ws://localhost:3100 HANDS=20 node playtest.js
MODE=winner HANDS=999 SETTINGS='{"buyIn":10000,"chips":10000,"sb":100,"bb":200,"blindMinutes":1,"maxRebuys":0}' URL=ws://localhost:3100 node playtest.js   # 1등 자동 종료
```

```bash
node test-practice.js   # 연습 테이블 서버 통합 시험 (봇 추가/삭제·나가기·끝까지 플레이·정산)
```

`bots.js` 는 화면 확인용 가상 플레이어입니다 (`node bots.js 방코드 인원수`).

## 참고

- 가상 칩으로만 진행합니다. 실제 돈이 오가는 용도로 쓸 때는 관련 법규를 확인하세요. 정산 화면은 계산 도구일 뿐 송금은 게임 밖에서 이뤄집니다.
- 방과 게임 상태는 서버 메모리에만 있어서 서버를 재시작하면 사라집니다.
